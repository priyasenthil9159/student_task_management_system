# Student Task Management System

## Description

The Student Task Management System is a web application developed using Python, Flask, and SQLite. It helps users manage their tasks through a simple web interface.

## Features

* User registration and login
* Task management
* SQLite database integration
* Web interface using HTML, CSS, and Bootstrap
* Session-based user authentication

## Technologies Used

* **Programming Language:** Python
* **Web Framework:** Flask
* **Database:** SQLite
* **Frontend:** HTML, CSS, Bootstrap
* **Template Engine:** Jinja2

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/student_task_management_system.git
```

### 2. Open the project folder

```bash
cd student_task_management_system
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows PowerShell:**

```powershell
.\venv\Scripts\Activate.ps1
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python app.py
```

### 7. Open in your browser

Visit:
http://127.0.0.1:5000

## Database

The application uses SQLite. The database file is created automatically by the application if database initialization is configured in the code.

## Purpose

This project demonstrates the development of a basic Python web application with database integration and task management functionality.
